# tickets

本平台接受商城签发的一次性登录票据，在**本地**验签后换取本地会话。

## raw source

这条边界是必须的：核查发现商城大部分服务端鉴权处于**被注释或未启用**状态，
因此**不得**以「商城网关已经校验过」为前提（genesis-evidence #171）。
信任一个你验证过并不生效的上游校验，是把授权建立在一条注释上。

## 不变量

- 票据是 RS256 JWT，公钥由商城侧**离线交付**。
- **公钥不可用时拒绝启动**——不静默降级为不验签。一个"验不了签但照常放行"的配置，
  比没有这道门更危险，因为**它看起来是有的**。
- 票据一次性消费：重放必须失败。
