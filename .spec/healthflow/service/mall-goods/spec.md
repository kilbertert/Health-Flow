# mall-goods

这条通路**必须**走服务端：商城网关的 CORS 头组合不合规（`Allow-Origin: *` 与
`Allow-Credentials: true` 同时出现，规范禁止），浏览器会拒绝该凭据请求，
且允许的请求头里不含租户与会话头。

## 不变量

- **浏览器不得直接调商城**；商品数据由本服务取回后出域。患者界面迁入商城 H5 之后浏览器
  改为跨源调用本仓（ADR 0026），这条不变量的内容不变：被禁止的是「浏览器直连商城」，
  不是「浏览器跨源」。
- 边界（ADR-0006）：本服务**不自持商品、不做商品可售性判断、不写商城任何状态**。
  可售性（审核通过 + 已上架 + 租户/门店归属）由商城在自己的端点里过滤，
  本模块只搬运，**不在其结果之上再加第二道闸门**。
