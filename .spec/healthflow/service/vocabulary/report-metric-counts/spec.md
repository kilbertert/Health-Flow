# report-metric-counts

「这份报告有多少项指标、其中有几项是异常的、有几项要患者处理」是患者界面上重复出现的
一句话，此前由**三处各自计算的计数**回答，判据互不同步：

- 历史摘要（`api/auth.py`）数判定为 `{H, L, A}` 的行，渲染成「· N 项异常」；
- 报告单总览（前端）自己再数一遍，**先剔掉 `excluded` 行**，用只认 `{H,L,A}` 的谓词；
- 确认页按"需要确认"另算一遍。

后果是患者可观察的：同一份报告在报告单说「未见异常指标」、在确认页说「N 项需要确认」；
**一行没判出来的指标让报告单印出「均在参考区间内」这句假话**。

## 不变量

- 三个界面读**同一个计数块**（两个契约各带同一个计数块，由本模块派生）。
- 计数是**服务端概念**：前端不得复算，也不得自造口径。
- `excluded` 是否计入异常，只有一处答案。
- **异常、在参考范围内、还没有判定是同一份判定的三个互斥出口**：三者之和等于已解析
  行数减去患者排除的行数；「在参考范围内」不得由减法求得（减法会把排除行说成正常）。
