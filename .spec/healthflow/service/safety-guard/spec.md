# safety-guard

位于**模型输出之后**，检查：具体剂量与服用频次、明确诊断或确定性疾病判断、仅凭单一指标下结论、
危急症状是否给出及时就医提示、是否包含医疗辅助免责声明。

## raw source

红旗输出**不会原样返回**，而是转换为保守的人工/就医提示。模型内 DPO 与模型外安全规则是
**互补层，不能互相替代**——把安全交给模型的自律，等于把"不诊断"这条约束换成一次概率。

## 不变量

- 检查在输出侧、**在出域之前**；入口处的过滤不能替代它。
- 命中即改写，不是记一条日志再放行。
